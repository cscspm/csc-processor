Set App Stage for a Single ID

Change one ID's App Stage directly instead of re-uploading the full App Stage sheet.

Reactivating a Permanently Closed ID? You don't need this tool for that anymore — just add the ID to the Missed IDs Queue and run Process & Export. It's automatically removed from Permanently Closed, its App Stage is set to 85, and it moves to Blocked. It only becomes Unblocked once it actually shows up in a later Verified daily report (confirming a real field visit) — this tool is for other manual App Stage corrections.

Fraud IDs: only fraud IDs with App Stage 84 or 89 are held back (Sheet 3). Fraud IDs at any other App Stage are still sent as usual — they're just noted in Sheet 3 for visibility, not blocked.

Go to Backup & Restore → Import the .json file. All data restored in seconds.
What is included in the backup:
✓ Master Blocked/Unblocked IDs (all entries)
✓ App Stage data (all CSC IDs + stage numbers)
✓ EKYC data (all unique IDs + dates)
✓ Fraud IDs (all flagged entries with details)
✓ Daily Report Log (every Verified/Non-Verified report row ever uploaded, with visit details — including IDs not in the master list)
✓ Unblock History (all dates you processed IDs)
✓ Permanently Closed history (all dates)

What is NOT included: The raw uploaded Excel files themselves and any in-progress "Process & Export" run that hasn't been saved yet — the row-level data from every daily upload (csc_id, visit details, report date) IS included via the Daily Report Log above.
